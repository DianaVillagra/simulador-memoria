# Simulador de Memoria - Partición Estática

## Descripción
Aplicación web que simula la administración de memoria mediante particiones fijas. Permite asignar procesos utilizando los algoritmos First Fit, Best Fit y Worst Fit, mostrando la fragmentación interna.

## Funcionalidades
- Asignación de procesos en memoria
- Algoritmos: First Fit, Best Fit y Worst Fit
- Visualización del estado de las particiones
- Cálculo de fragmentación interna

## Tecnologías
- HTML
- JavaScript
- GitHub Pages
